## 🌟 核心创新：为什么叫“超级指南针”？

市面上现有的学术提示词工具，大多是**“静态且硬编码”**的——它们逼着你在没理清思路前就输入具体的行业、甚至复杂的假设，极易导致 AI 产生幻觉或流于表面。

`SuperAcademic-Compass` 彻底颠覆了这种传统工作流，引入了**“动态漏斗机制”**：
1. **零门槛开局**：无需提前准备长篇大论的假设，从一轮简单的需求对齐（Step 0）开始。
2. **跨学科兼容**：无论你的领域是管理学、医学、计算机，还是完全未知的交叉学科，指南针都会动态调整航向。
3. **严谨收网**：通过递进式的 Markdown 工作流文件，将宽泛的兴趣一步步收窄为最稳固、最难被驳倒的论文选题与贡献陈述。
